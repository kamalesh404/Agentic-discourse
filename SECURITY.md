## Reporting a Vulnerability

Please do NOT report security vulnerabilities via public GitHub issues.

If you believe you have found a security vulnerability in Agentic-Discourse, please report it to `kamalesh404@users.noreply.github.com`. We will coordinate with you to resolve the issue safely.
